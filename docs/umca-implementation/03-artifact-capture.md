## Implementation

1. Trace producer → `internal/shell/{stream.go,capped_buffer.go,background.go,truncate.go,persist_message.go}` and `internal/agent/tools/bash.go` spill/polling, direct shell, backend shell flow (coordinate OPS). Inspect `safe.go` and changed Bash safety in branch; preserve existing permission and exit semantics. Inventory other dropping producers (tool result truncation, subagent reports, MCP if host has captured native representation); instrument before earliest byte loss where feasible. For each producer document observed byte format, separate vs merged stdout/stderr, canonical order, cancellation, existing ANSI stripping. `RunAndCaptureStream` shares writer: mark merged unless producer genuinely distinguishes; never reconstruct stream ordering from progress callbacks. Existing spills compatibility, not exact originals.
2. Implement scoped writer with store-owned opaque random ID, per-artifact + aggregate quotas (include temporary files and recovery reservations), atomic reservation across processes, bounded queue/chunk size and no indefinite producer backpressure. Tee at earliest reliable bytes before cap/ANSI/formatting; preserve binary and split UTF-8; if capture excludes content, store allowed representation only and mark redacted/partial, no byte-exact claim. Record observed count/boundary (unknown when upstream dropped), retained count, range manifest with original half-open offsets and retained digest per range/chunk, representation/version, capture origin and state: complete/capped/failed/expired/revoked/corrupt/missing. Empty complete ≠ failed. Head/tail preview lists omitted ranges; never concatenate and claim contiguous. Polling same background producer uses existing artifact/offset; no duplicate bytes. If writer stalls, bound queue; drop tracked ranges, preserve command exit status/progress. Respect capture off and explicit retention policy.
3. Write temp in private scoped root with restrictive modes, verify quota/digest/byte counts, close and atomic rename on same filesystem before ready metadata publication. Do not hold tx over writes. If claiming power-loss durable, use supported file + directory sync and prove; otherwise document process-crash guarantee only. Inject errors at temp create, write, close, rename, metadata commit; ENOSPC/permission/quota failures return bounded preview and truthful capture status, native command outcome unchanged. Reconcile rename-before-commit orphans, pending metadata, stale writer/reservations under STO cleanup journal. Sweep only owned paths after checking scope/active writers/reservations, never age alone. Account reservations on crash/retry. Quota & retention apply to rewind snapshots; coordinate REW separate recovery capacity and revocation precedence.
4. Implement scoped immutable expansion by handle+version and exactly one range unit (half-open bytes or line interval in known text), bounded I/O and returned bytes, authenticated chunk manifest or ingestion verification plus replacement/corruption detection. Reject mixed units, traversal, symlink substitution, unsupported link/representation, corrupt manifest, unauthorized (opaque unavailable). Authorized caller distinguishes partial/expired/missing/corrupt, actual available ranges/next cursor; no arbitrary filesystem paths or reading unbounded file for tiny excerpt. Recheck scope, source/policy generation just before return; cursors scope/version/representation/range/policy bound and tamper-resistant (coordinate REC). Implement reader lease/ref accounting; revoke access in STO tx, cleanup safe after active reader, repeated cleanup idempotent. Record source deps and allow deletion via same service; no paths in metadata errors that reveal other scopes.
5. Expose service contract to OPS for minimal exact inspect/expand/delete G2, REC lexical indexing of authorized text, REW before-images. Give fixture helpers synthetic producers, deterministic quotas/fault injection (filesystem interface or controlled errors), and scoped expand. Native messages bounded previews carry handles/status only where capture enabled; never change exit codes or persist hidden originals of excluded text. Test default off with existing shell output/truncation unchanged; keep authorized inspect/delete after switch off. Avoid broadening capture of credentials or provider opaque fields.
