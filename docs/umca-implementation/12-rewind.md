## I2 — local modes and recoverable apply

Implement list/preview/apply/status via service; OPS wires CLI/TUI/workspace. Four modes:
- Workspace only: restore eligible selected files, unchanged conversation frontier; record workspace revision/change, invalidate stale file/repo/task evidence.
- Conversation only: new active lineage at authorized retained legal prefix, abandoned suffix inactive historical subject present policy, workspace unchanged and evidence may be stale.
- Both: restore files then publish new frontier under recoverable journal, affected runs gated until resolved; no false global atomic FS/DB claim.
- Fork: independent conversation with scoped versioned prefix refs, source unchanged, physical workspace untouched, no Git branch creation. Workspace restore separate explicit decision.

Preview computes desired before-images reversing continuous attributable per-path log from current to selected point, validate joins of expected before/after and all intermediates (including create/delete/recreate/rename); same current digest alone doesn't fill gap. Other sessions' changes conflicts unless explicitly included under caller authority. Root/worktree/revision/type/mode/digest/bytes validation; preserve unrelated user dirty and staged changes, never move HEAD or index. Reject unsafe signed provider boundary, expired/deleted/unauthorized source or split tool group. Show path actions/conflicts/gaps, abandoned suffix, affected derivatives/tasks, external effects not reversed. Bind preview token to caller, mode, point/frontier, policy, workspace identity, selected paths/fingerprints. Apply must identify exact confirmed preview/mode/scope; stale token reject/recompute.

Apply protocol:
1. Acquire workspace mutation coordinator, quiesce affected sessions/subagents/queued writers across same/overlapping root; for conversation-only exclusive lineage admission. If unable, busy, user can cancel natively; headless same. Persist idempotency key+fingerprint, operation fence/generation and expected frontier, path preflight and bounded recovery before-images of current state. Gate new affected work; revalidate queued invocations against generation, explicit old-frontier queue outcome according to host. No DB tx across FS I/O.
2. Rooted resolution, recheck type, identity, digest/mode immediately on use; symlink/replacement/hardlink races fail safely. Stage private files on same target filesystem, quota account, supported atomic replace **per file**; record per-path intent durably before each change and observed outcome after. Journal created parent dirs and cleanup only operation-owned empty dirs. External editor independent; report races not safely resolved. Stage restore absent/create/delete/rename/modes/binary; handle partial success honestly.
3. After confirmed workspace success, conditional tx verifies fence, expected frontier/current policy/source validity; publish frontier, active-lineage eligibility, journal status together; workspace-only revision or conversation-only same frontier tx no FS. Reconcile coverage, observation/reflection cursors, task notes, memory/recall/search/jobs; default recall and learning exclude abandoned suffix and dependent records; independent evidence only if still valid. Failed compare even after files applied enters recovery. Retry after committed response loss returns existing result; fingerprint mismatch rejects idempotency key.
4. On restart/recover compare each unapplied/ambiguous intent with expected pre/post state, reauthorize. Known state reconcile or compensate after authoritative abort in reverse order only if applied fingerprints still match. Journal compensation intent/result durably; restore originally absent paths and pre-apply state. Cancellation after first mutation follows same path. Third-party change or missing/expired/revoked snapshot → `needs_resolution`, exact authorized paths/status and explicit retry/recover; keep journal/gate, no new frontier unless workspace succeeded. Revocation beats pin, do not retain hidden copy. Deletion applies to snapshots, lineage refs and payloads, minimal metadata as policy permits. No rewind means erasure or undo external effects/past disclosures.

## I3 — connected and distributed correctness

Integrate DST authority/fence; worker only proposes plan, owner Crush workspace applies. If journal/frontier separate, atomic per-op publication receipt with frontier mutation; on lost/unknown commit read authoritative receipt before compensation, keep gates until decision known. Persist idempotency key across local/connected retries; revalidate stale preview after migration/authority epoch. Same workspace API and TUI/CLI semantics, no bypass by older client. Test cross-store partition during publication, lost response and queued work terminal once; startup recovery before admitting new work. Revoke inherited source during fork/apply/historical query, no revival via snapshots or abandoned branch.
