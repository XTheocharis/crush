## D1 — speculative retrieval and helper

1. Prefetch only eligible run/query snapshot keyed by accepted run, task/query identity, source/index generation, policy; immutable refs not raw prompt copies. Bound concurrency, deadlines, bytes/tokens/spend, cancel on task change/new generation/disable/shutdown. Never wait on critical path past configured deadline; use ordinary REC path or no optional recall. Backend ignoring cancellation cannot insert stale results into projection or durable cache; reauthorize at consumption against current scope, versions/index/policy; cancel/revoke races after selection and before admission. Default metadata-only traces (purpose, IDs/status/latency); no new raw payload logging.
2. Restricted helper agent delegated principal no broader than caller, isolated request/session state; explicit allowlist search, scoped expand, evidence inspect. No shell/edit/write, tool replay, external messaging, retention/share/memory mutation, recursive spawning; reject at host resolver and executor, not just prompt. Limit step/depth/output/concurrency/spend; each call HST purpose+effective model admission and independent opt-in/egress. Tool snippets hostile data: prompt injection cannot widen tools/scope. Return evidence handles + quoted ranges and separately labeled inference; host validates handles/version/span/current eligibility before use. On invalid citations omit/reject with reason; no automatic memory promotion. Scope in tool arguments narrows only. No helper execution on unavailable/denied grant.

## D2 — interoperable read-only server

Inspect `internal/agent/tools/mcp/init.go` and pinned `github.com/modelcontextprotocol/go-sdk` in go.mod. Existing Crush MCP client registration is not a server. Implement explicit opt-in MCP endpoint backed by same workspace REC API, `context_search` and `context_expand` with bounded typed schema, source status/method/representation, opaque cursor and expansion bounds. Negotiate only SDK protocol revisions actually tested; record pinned revision in client/server fixtures. Authenticate caller and map to allowed scopes independent of query and session IDs; rate limit by client, cancellation and deadline, no control of policy or mutations. Revalidate grant on every invocation/reconnect/cursor consumption. For stdio explicitly bind process to workspace/principal, logs stderr not protocol stdout. For Streamable HTTP local-only bind loopback by default, validate Origin if present, auth per request independent of client-provided MCP session ID; external bind requires authorized deployment policy, never default. Reject invalid Origin, wrong principal, stale/revoked grant/altered cursor; unavailable response opaque. Return identical authorized semantic payload to native APIs including partial status. Respect existing tool allowlists and no bypass of host permissions when a Crush client calls server. Implement graceful close, idle sessions and in-flight cancel; no secret or source payload in default logs/broker.
