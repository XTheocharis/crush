## C1 — local indexing and retrieval

- Chunk finalized allowed text by logical boundaries (messages, code/file sections), bounded UTF-8 bytes/tokens, source ID/version and half-open **byte** range, chunk digest + representation. No opaque signatures/binary metadata/credential fields. Check code-point boundaries, normalize only into explicitly new representation/version; if adapting JS reference UTF-16 offsets convert against exact source, reject split surrogate/astral boundary, quote mismatch. Derive source/policy dependencies; stale chunks unusable even before cleanup.
- Implement embedding backend interface with local deterministic fixture and actual selected local or explicitly authorized remote embedding backend chosen with orchestration decision (name/model/dimensions, licensing, resource/installation tradeoff); remote optional provider independently authorized for text egress/spend. Keep consent separate from detected capability; no external call in default tests. Job inputs immutable refs, resolve live before send with origin admission; if remote origin unavailable deny. Model/version, dimension, normalization, distance metric and index generation persisted; no comparing incompatible dimensions/models. Use scope-partitioned local vectors and bounded exact similarity over eligible set, not global ANN then postfilter. Add upsert/search/delete/rebuild API and revision checks, deterministic score tie-break. Expose partial coverage/index lag/outage separately from no matches. Cap indexing jobs/backfill concurrency, quotas and cost; source/policy changes fence jobs.
- Retrieve authorized exact handle/file identity first, bounded lexical and vector sets, deterministic reciprocal rank fusion (or justified deterministic equivalent), dedup source/version families, total bytes/tokens/time; no cache initially. Query expansion optional budgeted synonyms/language variants under same scope/deadline. Reranker sends only eligible IDs and bounded excerpts after new admission, returns ordered subset; drop invented/duplicate IDs, append eligible omitted candidates in baseline order, fallback lexical/fused on timeout/outage. Reauthorize live rows at result/snippet return, prior model egress and retry. Track method, completeness, coverage, purpose usage, no treating vector score as truth.
- Shadow generation upgrade: stage new model/index from authorized source watermark, validate coverage and held-out results, atomically switch reader, bounded rollback retaining only still-authorized records; delete superseded vectors; deletion/tightened policy affects both generations and queue/receipts. Add deterministic outage and rollback via OPS.
