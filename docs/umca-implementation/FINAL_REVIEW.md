Actual Go 1.27.4 toolchain, supported targets, selected SDK wire/stream/retry contracts, real SQLite/PostgreSQL/pgvector/RabbitMQ, filesystem semantics, provider security/cost facts and actual consented enabled paths remain implementation-time gates. The local available Go is 1.23.2; the preceding review could not live-clone in this environment. No new assertion that HTTPS fetching works or all upstream references remain reachable indefinitely is made.
- The prior review verified live commit/tree and indexed blob identities for all 20 reference repositories; this pass reverified their supplied archive bytes and current Crush refs, not a new live fetch of every reference branch or current security advisory sweep. Pins are reproducibility anchors; they are not the latest dependency recommendations.
- Git protocol tests exercise the important local ref/ancestry invariants, not the full scheduler, actual runner lock/journal fsync or crash recovery. The runbook is executable instructions and illustrative commands, not a deployed autonomous scheduler. Python 3.9+ and compatible Git tooling are orchestration prerequisites (validate exact version and supported flags); Python is not a Crush dependency. Marker helper is not a language parser, a trust boundary for hostile local Git repositories, or proof of independent approval. Helper output hashes depend on the actual Git version/config/attributes; keep exact evidence and independent review. Use a trusted private cache and approved network configuration, and no unverified clone substitutes.
- Architectural decisions without additional user selection: keep pinned fork rather than auto-sync a moving main, retain first proposed Anthropic adapter subject to the U01 spike, use journaled compare-and-swap Git promotion rather than merge/revert, preserve historical findings and verbatim documents, allow exact externally delimited exceptions when inline markers would corrupt machine-owned/commentless formats. All runtime requirements and all original A–I streams remain. No review can certify every future implementation detail from static plans alone; U00, per-unit independent AUD and QA, G1–G7 and U14 remain mandatory.
